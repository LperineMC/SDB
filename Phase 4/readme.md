This directory contains materials to document Phase 4,evaluation of the generated SDBs using automated LLM judges deployed along two distinct evaluation tracks: 

•	Adapted RAG Triad Performance Audit: This technical evaluation assesses the underlying technical retrieval performance of the three architectures that are tested in the experimental design. If uses an adapted RAG Triad rubric to score Faithfulness (Groundedness), Contextual Depth (Recall), and Interpretive Specificity (Answer Relevance)
